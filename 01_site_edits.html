Category 04 · Structural, SEO, and housekeeping

Most of the previous fixes are content. The next twelve are infrastructure. Without these, the content lands but no one finds the site, share previews look broken, conversion paths leak, and Lighthouse scores tank. None are dramatic. All are required.

Edit 14 · SEO · meta titles and descriptions on every page

Most pages on siderroad.com likely use default page titles (e.g. "Sider Road" repeated) and have empty or generic meta descriptions. This kills both search ranking and click-through from search results.

Fix

  • Unique meta title per page · format · [Page topic] · Sider Road · max 60 characters
  • Unique meta description per page · 140-155 characters, written like a search result snippet
  • Homepage example title · Family Business Advisory and Speaker · Sider Road
  • Homepage example description · Jocelyn Greenky Underwood guides family-owned businesses through the leadership transitions that decide whether they survive a generation. Advisory, masterminds, speaking.
  • Apply across all ~15 site pages

Edit 15 · SEO · Schema.org structured data

Lets Google show rich result enhancements (sitelinks, knowledge panel, speaker schema). Currently almost certainly missing. Major SEO uplift for branded searches like "Jocelyn Greenky."

Add

  • Person schema on /jocelyn/ · name, image, jobTitle, sameAs (LinkedIn, X, IG, HuffPost), alumniOf, knowsAbout
  • Organization schema on homepage and footer · Sider Road LLC, address (Greenwich CT), founder, employee, sameAs links
  • Event schema on /speaking/ for any upcoming public talk
  • Book schema on /the-book for Big Sister's Guide + Design Your Reputation
  • BreadcrumbList schema sitewide
  • Test with Google Rich Results Test before launch

Edit 16 · SEO · Open Graph and Twitter Card meta

When anyone shares a Sider Road link on LinkedIn, X, Slack, or email preview tools, what do they see? Probably nothing or a broken default. Fix once, every share preview is on-brand from that point on.

Add

  • og:title, og:description, og:image (1200×630), og:url, og:type on every page
  • twitter:card set to summary_large_image, plus twitter:title and twitter:description
  • Default share image · branded card (drop Jocelyn headshot + Sider Road logo + tagline) · save as /img/share-default.jpg
  • Page-specific override on /epk, /speaking, /the-book, /reputation-by-design
  • Test with metatags.io and LinkedIn Post Inspector before launch

Edit 17 · UX · Calendly CTA segmentation

Currently 8+ CTAs across the site all point to a single Calendly URL. No way to know whether a booking came from the speaking page, a mastermind page, or the contact form. This kills conversion attribution and forces Jocelyn to ask "how did you find me" on every call.

Fix

  • Create 4 separate Calendly event types · Speaking inquiry · Mastermind consult · Advisory consult · Press / media
  • Each page's CTA points to the right one
  • Each Calendly event includes a custom question (e.g. speaking version asks event date + audience size)
  • UTM parameters appended for clean analytics attribution

When the broken pages from Edits 01 and 02 get restored, any historical inbound links (LinkedIn posts, podcast show notes, email signatures) need to land in the right place. Set up 301 redirects from any old URLs to the new canonical ones.

  • /downloads should accept both /downloads and /downloads/

Edit 20 · Technical · page speed audit and image optimization

Lighthouse score baseline check first. Then optimize. Slow sites die in search rankings and lose mobile visitors who bounce after 3 seconds.

Fix

  • Run Lighthouse audit on homepage + /jocelyn/ + /downloads/ · record baseline
  • Compress all hero images to WebP, max 300KB
  • Add native loading="lazy" to below-the-fold images
  • Defer non-critical JS
  • Audit font loading · use font-display: swap
  • Target · Lighthouse Performance ≥ 85 on mobile

Edit 24 · UX · Accessibility audit

Alt tags missing on images, color contrast issues, keyboard navigation gaps. Most sites fail WCAG AA. Both moral and legal reason to fix (ADA enforcement is rising in service-business industries).

Fix

  • Alt text on every image · descriptive, not "image1.jpg"
  • Run axe DevTools audit · fix everything tagged Critical or Serious
  • Color contrast minimum 4.5:1 on body text
  • All links keyboard-accessible (tabindex, focus states visible)
  • ARIA labels on Calendly CTAs, social icons, hamburger menu
  • Document remaining gaps in an accessibility statement page · /accessibility/

  • Privacy policy and terms links added (update both with current year)
  • Social icons updated · LinkedIn, X, Instagram, YouTube if applicable
  • Copyright year auto-updates via JS

Mobile audit

  • Test hamburger menu, all CTAs, every form, all download links
