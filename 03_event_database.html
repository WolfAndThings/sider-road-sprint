Pitch tracker · the engine

Without tracking, nothing compounds. Build this once and every pitch downstream gets logged, tagged, and followed up on a real cadence.

Google Sheet structure

Columns, left to right:

  1. Event / Podcast name
  2. Type · event / podcast / bureau
  3. Tier · 1-6 (events) or A-C (podcasts) or premium/marketplace (bureaus)
  4. Organizer / Host
  5. Direct contact · email + LinkedIn URL
  6. Template used · 01 / 02 / 03 / 04
  7. Status · researched / pitched / replied / accepted / declined / booked / paid / followed-up
  8. Pitched date
  9. Replied date
  10. Reply quality · 1-5
  11. Fee discussed
  12. Talk pitched · which signature talk
  13. Next follow-up date
  14. Notes

Color-coding · green = accepted/booked, yellow = replied/needs follow-up, red = declined, grey = no reply 14+ days.

Cadence rules

  • Day 0 · pitch sent
  • Day 10 · single polite follow-up if no reply
  • Day 21 · final follow-up with new hook (recent press, podcast, post)
  • Day 45 · move to dormant, retry at Q3 with different angle
What goes into Phase 2 (Date Project · $2,450)
  • Verify 2026 CFP deadline dates for every event Tier 1-6
  • Identify direct contact (not info@) per event via LinkedIn recon
  • Send 30+ personalized warm-flattery pitches (events)
  • Send 20 podcast pitches
  • Pitch tracker built + populated for every target above
  • 10-day + 21-day follow-up cadence run
